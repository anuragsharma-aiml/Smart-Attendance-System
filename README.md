 # Smart Attendance System

A QR code-based Smart Attendance Management System built with Python, Flask, SQLite, HTML, CSS and JavaScript.

## 📌 Overview

Smart Attendance System is a web-based attendance management application that allows students to mark their attendance by scanning a QR code generated by the teacher.

The system provides separate dashboards for students and teachers, making attendance management simple, fast and organized.

## ✨ Features

- Student Login
- Teacher Login
- Student Dashboard
- Teacher Dashboard
- QR Code Generation
- QR Code Scanning
- Automatic Attendance Marking
- Student Attendance Records
- Teacher Attendance Dashboard
- Attendance Report
- SQLite Database
- Session-based Login and Logout

## 🛠️ Technologies Used

- Flask
- SQLite
- HTML

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/anuragsharma-aiml/Smart-Attendance-System.git
cd Smart-Attendance-System
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the virtual environment

For Windows PowerShell:

```bash
venv\Scripts\Activate.ps1
```

### 4. Install required packages

```bash
pip install flask
```

### 5. Run the application

```bash
python app.py
```

### 6. Open in browser

```text
http://127.0.0.1:5000
```

## 🔄 System Workflow

1. Teacher logs into the system.
2. Teacher generates a QR code.
3. Student logs into the system.
4. Student scans the QR code.
5. Attendance is automatically marked.
6. Teacher can view attendance records.
7. Attendance reports can be viewed.
8. Student can view their attendance.

## 🎯 Project Purpose

This project is designed to simplify attendance management using QR code technology and reduce manual attendance work.
