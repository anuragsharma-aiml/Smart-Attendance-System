# Smart Attendance System

A QR code-based Smart Attendance System developed using Python and Flask.

# Features

- Student login
- Teacher login
- QR code generation
- QR code scanning
- Automatic attendance marking
- Student attendance records
- Teacher attendance dashboard
- Attendance report
- SQLite database

# Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- QR Code

# How to Run

# 1. Clone the repository

```bash
git clone https://github.com/anuragsharma-aiml/Smart-Attendance-System.git
cd Smart-Attendance-System
```

# 2. Create a virtual environment

```bash
python -m venv venv
```

# 3. Activate the virtual environment

```bash
venv\Scripts\Activate.ps1
```

# 4. Install required packages

```bash
pip install flask
```

# 5. Run the application

```bash
python app.py
```

# 6. Open in browser

```text
http://127.0.0.1:5000
```

# Project Purpose

This project is designed to simplify attendance management using QR code technology and reduce manual attendance work.
